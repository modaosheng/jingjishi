# 打包与部署指南

> 目标：把《经师 AI》装到手机上，像 App 一样使用。
> 两条路线：**PWA**（零依赖，现在就能用）与 **APK**（需 Android 工具链）。

---

## 一、PWA（推荐先做）

### 为什么先做 PWA

| 优势 | 说明 |
|---|---|
| 零依赖 | 项目已配好 `vite-plugin-pwa`（manifest / 图标 / Service Worker / 自动更新） |
| **SQLite 可用** | PWA 走 **HTTPS = 安全上下文** → OPFS 可用 → **不会再降级为 Mock** |
| iOS 也能用 | 不依赖 Android 工具链；APK 方案在 Windows 上打不了 iOS |
| 成本低 | 部署一次，后续更新用户自动拿到 |

### 1. 构建

```bash
cd app
npm run build
```

产物在 `app/dist/`。

### 2. 部署（必须 HTTPS）

PWA 的安装能力**要求 HTTPS**（`localhost` 除外）。三种方式：

**方式 A · 临时验证（最快）**
```bash
cd app
npm run preview -- --host
```
手机与电脑同一 Wi-Fi，浏览器打开 `http://<电脑IP>:4173`。
⚠️ 此时是 **http**，不是安全上下文，**SQLite 会降级** —— 只用于看界面，不适合验证数据功能。

**方式 B · 内网穿透（推荐，能拿到真实 HTTPS）**
```bash
npx localtunnel --port 4173
# 或用 ngrok / cloudflared 等
```
拿到 `https://xxx.loca.lt` 后手机访问 —— **此时是安全上下文，SQLite 正常**。

**方式 C · 正式部署**
把 `dist/` 传到任意静态托管（Vercel / Netlify / 对象存储 + CDN），绑定域名即可。

### 3. 手机安装

**Android（Chrome / Edge）**
1. 用浏览器打开站点
2. 底部会自动出现「**装到桌面，像 App 一样用**」卡片 → 点「立即安装」
3. 或手动：浏览器菜单 → 「安装应用」/「添加到主屏幕」

**iOS（Safari）**
1. 必须用 **Safari**（Chrome/微信内置浏览器不支持）
2. 点底部「分享」按钮 → 下滑找到「**添加到主屏幕**」→ 添加
3. 打开时会给出对应引导卡片

### 4. 验证清单

- [ ] 桌面出现图标，打开后**无地址栏**（standalone）
- [ ] 「我的 → 存储信息」显示 **SQLite (OPFS)**，不是「内存 Mock」
- [ ] 飞行模式下仍能打开（Service Worker 缓存生效）
- [ ] 「我的」页顶部出现新版本提示时，点「立即更新」能刷新到新版本

> **iOS 注意**：未添加到主屏幕时，Safari 7 天不活跃会清空本地存储。
> 这是系统行为 —— 所以务必要「添加到主屏幕」，并定期用「导出备份」。

## 二、Android APK（Capacitor）

> 配置文件 `app/capacitor.config.ts` **已就绪**（`androidScheme: 'https'`，
> 保证 App 内是安全上下文 → SQLite 可用）。

### 前置环境（需在你本机安装）

| 依赖 | 版本 | 说明 |
|---|---|---|
| **JDK** | 17 或 21 | Capacitor 7 要求 JDK 17+ |
| **Android Studio** | 最新版 | 含 Android SDK（约 10GB） |
| **环境变量** | `ANDROID_HOME` | 通常在装完 Android Studio 后自动配置 |

### 打包步骤

```bash
cd app

# 1. 安装 Capacitor 依赖
npm i -D @capacitor/cli
npm i @capacitor/core @capacitor/android

# 2. 构建 Web 产物
npm run build

# 3. 生成原生工程（只需执行一次）
npx cap add android

# 4. 同步 Web 产物到原生工程（每次改完代码都要执行）
npx cap sync

# 5. 用 Android Studio 打开并出包
npx cap open android
```

在 Android Studio 中：
- 调试运行：直接点 ▶ Run
- 生成安装包：`Build → Build Bundle(s) / APK(s) → Build APK(s)`
- 上架用的签名包：`Build → Generate Signed Bundle / APK`

### 常用命令

```bash
npx cap sync          # 改完 Web 代码后同步（= cap copy + cap update）
npx cap run android   # 命令行直接跑到设备
npx cap doctor        # 检查环境是否就绪
```

### 注意事项

- **每次改完前端都要 `npm run build` + `npx cap sync`**，否则 App 里还是旧代码
- `android/` 目录会被生成（几万个文件）——**建议加入 `.gitignore`**，用 `npx cap add android` 可重建
- iOS 需要 **macOS + Xcode**，当前 Windows 环境无法构建

## 三、常见问题

**Q：手机浏览器提示「不支持 SQLite，已降级为 Mock」？**
用 http 经局域网 IP 访问时，OPFS 被浏览器禁用（非安全上下文）。改用 **https**（内网穿透或正式部署），或直接装 App。

**Q：PWA 装完后数据会丢吗？**
不会（除非卸载或清除站点数据）。但 iOS 若**未添加到主屏幕**，Safari 7 天不活跃会清空存储 —— 务必添加到主屏幕，并定期在「我的」页导出备份。

**Q：能上应用商店吗？**
Android 可以（APK/AAB）；iOS 需要 Mac 构建 + 开发者账号。

**Q：APK 和 PWA 数据互通吗？**
**不互通**。两者的存储是隔离的。切换时请先用「导出备份」再在新端「导入恢复」。
